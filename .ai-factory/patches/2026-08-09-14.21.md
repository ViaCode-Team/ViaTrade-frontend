# Treat a missing strategy as an empty binding list

**Date:** 2026-08-09 14:21
**Files:** `src/features/strategy/bind-stock/model/use-strategy-linked-stock-ids.ts`
**Severity:** medium

## Problem

Opening stock bindings could fail in the query boundary when
`GET /api/v1/strategies/{strategyId}/instruments` returned `404` with
`strategy_not_found`.

## Root Cause

The query treated every HTTP error as unexpected. The binding interface needs
an empty selected-ID set when the requested strategy no longer exists.

## Solution

Handle a `404` from the initial linked-instruments request as an empty list.
Other errors, and errors while loading remaining pages, still propagate to the
query boundary.

## Prevention

- Classify expected API errors in the owning query instead of suppressing all
  request failures.
- Add a query-level regression test for the `404` empty-selection case when
  test infrastructure is introduced.
