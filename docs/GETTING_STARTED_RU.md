# Начало работы

## Требования

- Node.js и npm. В репозитории пока не задано поле `engines`.
- Backend, доступный через настроенный прокси `/api`, для сценариев с авторизацией и серверными данными.

## Установка и запуск

```bash
npm install
npm run dev
```

Vite запускает dev-сервер. В текущей конфигурации разработки frontend проксирует запросы `/api` на `https://localhost:7249`.

## Проверка настройки

После изменений исходного кода или документации запустите общую проверку:

```bash
npm run check:fix
```

Команда запускает исправление ESLint, проверку TypeScript, валидацию FSD через Steiger и форматирование Prettier. При успешной проверке Steiger выводит `No problems found!`.

Pre-commit hook запускает `lint-staged`. В Windows он разбивает staged-файлы на команды не длиннее 7000 символов, поэтому коммит с большим числом файлов не превысит ограничение длины командной строки.

## Справочник команд

Ниже перечислены все scripts, которые сейчас объявлены в `package.json`.

| Команда              | Когда использовать                                                              |
| -------------------- | ------------------------------------------------------------------------------- |
| `npm run prepare`    | Чтобы вручную переустановить Husky hooks; npm также запускает ее после install. |
| `npm run dev`        | Локальная разработка frontend.                                                  |
| `npm run build`      | Проверка типов и создание production-сборки.                                    |
| `npm run preview`    | Локальная проверка production-сборки.                                           |
| `npm run api:gen`    | Изменились `swagger.yaml` или настройки генерации API.                          |
| `npm run types`      | Проверка TypeScript без production-сборки.                                      |
| `npm run lint`       | Проверка правил ESLint без изменения файлов.                                    |
| `npm run lint:fix`   | Автоматическое исправление ESLint с последующей проверкой diff.                 |
| `npm run arch`       | Проверка границ Feature-Sliced Design через Steiger.                            |
| `npm run arch:fix`   | Применение безопасных архитектурных исправлений Steiger.                        |
| `npm run format`     | Проверка форматирования через Prettier.                                         |
| `npm run format:fix` | Применение форматирования Prettier.                                             |
| `npm run check`      | Полная проверка lint, типов, архитектуры и форматирования.                      |
| `npm run check:fix`  | Исправление lint/архитектуры/форматирования и проверка TypeScript.              |
