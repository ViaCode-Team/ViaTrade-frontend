# ViaTrade Frontend

> Прогрессивное веб-приложение для инвестиционного анализа, торговых сценариев и защиты локальных данных.

ViaTrade объединяет стратегии, финансовые инструменты, сделки, сигналы, заметки, напоминания и статистику портфеля в одном React-приложении. Интерфейс на Mantine дополнен сгенерированным API-клиентом, постоянным кешем серверных данных и локальной PIN-блокировкой чувствительных данных браузера.

> [!WARNING]
> **Проект в разработке.** Функции и пользовательские сценарии могут меняться.

## Быстрый старт

В существующей рабочей копии установите зависимости и запустите dev-сервер:

```bash
npm install
npm run dev
```

Для запросов к `/api` используется dev-прокси из `config/vite/proxy.ts`; перед проверкой сценариев с авторизацией запустите backend, соответствующий вашему окружению.

## Возможности

- **Торговые сценарии** — стратегии, инструменты, сделки и автоматически созданные сигналы.
- **Личный контекст** — заметки и черновики напоминаний для инструментов и стратегий.
- **Защита данных браузера** — шифрование сохраненных данных и локальная разблокировка по PIN.
- **Адаптивный интерфейс анализа** — дашборды, статистика, светлая и темная темы.
- **Типобезопасный API** — React Query hooks и TypeScript-контракты из `swagger.yaml`.

## Первый сценарий

1. Запустите frontend и backend, ожидаемый вашим локальным окружением.
2. Войдите в приложение и завершите настройку локального PIN, когда приложение ее запросит.
3. Откройте стратегию или инструмент, чтобы работать с данными, связанными сигналами, заметками и напоминаниями.

PIN — это локальный уровень защиты браузера; он не заменяет backend-аутентификацию. Поведение хранилища и блокировки описано в [разделе безопасности](SECURITY_RU.md).

## Частые команды

Полный справочник команд, включая проверки и автоисправления, приведен в [Начале работы](GETTING_STARTED_RU.md).

| Команда             | Назначение                                           |
| ------------------- | ---------------------------------------------------- |
| `npm run dev`       | Запустить Vite dev-сервер.                           |
| `npm run build`     | Проверить типы и собрать production-версию.          |
| `npm run api:gen`   | Сгенерировать API-клиенты и общие экспорты типов.    |
| `npm run check:fix` | Исправить lint/форматирование, проверить типы и FSD. |
